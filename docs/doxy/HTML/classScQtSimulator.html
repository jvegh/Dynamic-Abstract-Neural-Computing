#include <ScQtSimulator.h>

Detailed Description

Implements a semi-general SystemC simulator, based on Qt technology.

The idea is that the simulator repeatedly starts the SystemC engine (internally stopping at next SystemC event, generated by the tested system). It is assumed that the system-under-test unit generates events such as "heartbeating", that is, the system steps from one simulated time to the other, an the time adapts to the actual situation. After the steps, the simulator simulator performs a delay, allowing to slow down the apparent execution.

It benchmarks three types of execution times: the simulated (biological) time, the simulated time (the processor time to process the algorithms) and the user time (the typically interactive user needs to browse the simulation). The times can be reset.
