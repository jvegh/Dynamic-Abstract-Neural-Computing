\doxysubsection{Detailed Description}
Implements a general biological-\/type computing PU. Defaults to variable (that is, biologically defined) execution time, no central clock. 

In the corresponding states, the neuron is in one of its \doxylink{classGenCompStageMachine__t}{Gen\+Comp\+Stage\+Machine\+\_\+t} states
\begin{DoxyItemize}
\item Gen\+Comp\+Stage\+Machine\+\_\+t\+::gcsm\+\_\+\+Computing\+: computing (collects charge)
\item Gen\+Comp\+Stage\+Machine\+\_\+t\+::gcsm\+\_\+\+Delivering\+: delivers action potential
\item Gen\+Comp\+Stage\+Machine\+\_\+t\+::gcsm\+\_\+\+Relaxing\+: restores resting potential
\end{DoxyItemize}

The sc\+Gen\+Comp\+\_\+\+PU\+\_\+\+Abstract\+::\+Heartbeat\+\_\+method() handles an internal \textquotesingle{}update\textquotesingle{} signal. Internally it branches to \doxylink{classscGenComp__PU__Abstract_af93f673da1a0605463ebe7c472ee061f}{sc\+Gen\+Comp\+\_\+\+PU\+\_\+\+Abstract\+::\+Heartbeat\+\_\+\+Computing\+\_\+\+Do()}, \doxylink{classscGenComp__PU__Abstract_ac6b3b05527c3559773621b905430542f}{sc\+Gen\+Comp\+\_\+\+PU\+\_\+\+Abstract\+::\+Heartbeat\+\_\+\+Delivering\+\_\+\+Do()} or \doxylink{classscGenComp__PU__Abstract_a0a827655bc1a3e0affd9f3e4c28d4d27}{sc\+Gen\+Comp\+\_\+\+PU\+\_\+\+Abstract\+::\+Heartbeat\+\_\+\+Relaxing\+\_\+\+Do()}, as the current \doxylink{classGenCompStageMachine__t}{Gen\+Comp\+Stage\+Machine\+\_\+t} requires. Usually, it calls Calculate\+\_\+\+Do().

During processing, it calls a Heartbeat\+\_\+\+XXX\+\_\+\+Stop() method to see if heartbeating in the current state should be stopped. It advances to the next stage or stops heartbeating.

(It is {\itshape NOT} a central clock signal; it refreshes only the SIMULATED time.) In the corresponding states, the neuron is
\begin{DoxyItemize}
\item Gen\+Comp\+Stage\+Machine\+\_\+t\+::gcsm\+\_\+\+Relaxing\+: Until it reaches its resting potential, calls Calculate\+\_\+\+Do(). Upon receiving an input, changes to state Gen\+Comp\+Stage\+Machine\+\_\+t\+::gcsm\+\_\+\+Computing. Inputs enabled\+: the relative refractory period.
\item Gen\+Comp\+Stage\+Machine\+\_\+t\+::gcsm\+\_\+\+Computing\+: Until it reaches its threshold potential, calls Calculate\+\_\+\+Do(). At that point, changes to state to state Gen\+Comp\+Stage\+Machine\+\_\+t\+::gcsm\+\_\+\+Delivering. Inputs enabled.
\item Gen\+Comp\+Stage\+Machine\+\_\+t\+::gcsm\+\_\+\+Delivering\+: Until it reaches its lowest membrane potential (its increase turns from negative to positive), calls \doxylink{classscGenComp__PU__Bio_af018b6c96d882c6173f0966d104b3898}{Heartbeat\+\_\+\+Relaxing\+\_\+\+Do()}. At that point, changes to state to state Gen\+Comp\+Stage\+Machine\+\_\+t\+::gcsm\+\_\+\+Relaxing, without restoring membrane\textquotesingle{}s potential. At the beginning issues signal \textquotesingle{}Transmitting\+Begin\textquotesingle{}. Signal transmission happens in parallel with the further processing. Inputs disabled; the absolute refractory period.
\end{DoxyItemize}

The Input\+Received\+\_\+method()\+: the unit received new input (a momentary state). Only administrative action; the received input is handled in Heartbeat\+\_\+method(), as described in Calculate\+\_\+\+Do(). Disabled in mode Gen\+Comp\+Stage\+Machine\+\_\+t\+::gcsm\+\_\+\+Delivering.
