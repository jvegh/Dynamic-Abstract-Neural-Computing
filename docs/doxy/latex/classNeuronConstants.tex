\doxysubsection{Detailed Description}
Sources\+: 

Provide neuron-\/related constants in various relations for neural computing

Define neuron\textquotesingle{}s constants Provides access functions to the parameters of the neuronal condenser and resistor

The system uses numbers in units\+:
\begin{DoxyItemize}
\item resistivity GOhm so \mbox{[}R\mbox{]} ( $10^9$ Ohm)
\item capacity pF so \mbox{[}C\mbox{]} ( $10^{-12}$ Farad
\item time ms so \mbox{[}t\mbox{]} ( $10^{-3}$), so \mbox{[}R\texorpdfstring{$\ast$}{*}C\mbox{]} is ( $10^9*10^{-12}=10^{-3}$)
\item voltage mV so \mbox{[}V\mbox{]} is ( $10^{-3}$)
\item current pA ( $10^{-12}$)
\item so current from V/R $ 10^{-3}/10^{9}=10^{-12} $ pA
\item so \mbox{[}I/C\mbox{]} ( $10^{-12}/10^{-12}$ V/s)
\item so $ \frac{1}{C}\frac{dI}{dt} = [A/s/(As)*V] = [Cb/s^2] $
\item so \mbox{[}I\texorpdfstring{$\ast$}{*}R\mbox{]} ( $ 10^{-12}*10^9$ = mV)
\item so \mbox{[}V/C\mbox{]} ( $10^{-3}/10^{-12} = 10^9 V/m$) 
\end{DoxyItemize}
