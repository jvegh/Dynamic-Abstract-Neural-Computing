2.1 Modeling methods

”There is a widely accepted distinction between merely modeling a mechanism’s behavior and explaining it. …Some models are data summaries. Some models sketch explanations but leave crucial details unspecified or hidden behind filler terms. Some models are used to conjecture a how-possibly explanation without regard to whether it is a how-actually explanation.”[MechanisticModelHodgkinHuxleyCraver:2006].
